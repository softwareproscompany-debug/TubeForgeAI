# Security Policy

Thank you for taking the time to look out for the security of TubeForgeAI. We take security reports seriously — please follow the guidance below to report vulnerabilities responsibly.

## Supported Versions
We actively maintain and provide security fixes for the latest release. If you are unsure which versions are supported, open an issue or contact us as below.

## How to Report a Vulnerability
Preferred method:
- Email: security@softwareproscompany-debug (replace with the address you want to use)

If email is not available, create a private security issue in this repository and tag it "security". If you cannot create a private issue, please contact us on the email above.

When reporting, please include:
- A clear description of the vulnerability and the steps to reproduce it.
- The version(s) of TubeForgeAI that are affected.
- Any proof-of-concept code or logs that help reproduce the issue.
- Your contact information so we can follow up.

## Public Disclosure and Timeline
We ask that reporters give us a reasonable period to investigate and remediates issues before public disclosure. Our typical timeline is:
- 0–3 business days: Acknowledgement of receipt.
- 7–30 calendar days: Initial investigation and proposed mitigation or fix (may vary by severity).
- We will coordinate disclosure timing with the reporter; in exceptional cases we may request more time to prepare a patch or coordinate with downstream projects.

If you need a quicker response due to an active exploit or high severity, mark the report as high priority in the email subject.

## Reporting Sensitive Data
Do not attach large sensitive files publicly. Use encrypted communication where necessary. If you prefer encryption, include your PGP public key in your first message and we will use it for follow-up.

## After a Fix
When a fix is available we will:
- Publish a security advisory (if applicable) detailing the issue and mitigation steps.
- Provide guidance for upgrades or patches.
- Credit reporters if they wish, unless they request anonymity.

## Contact
Email: security@softwareproscompany-debug

Thank you — we appreciate responsible disclosures that help keep TubeForgeAI safe.
